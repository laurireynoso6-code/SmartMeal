# SmartMeal

SmartMeal es un prototipo web navegable desarrollado como proyecto académico para la carrera de Tecnicatura Superior en Desarrollo de Software.

## Descripción

La plataforma propone ayudar a las personas a organizar los alimentos disponibles en casa, descubrir recetas prácticas y planificar comidas durante la semana.

## Problema

Muchas personas no saben qué alimentos tienen disponibles, desperdician productos por vencimiento o pierden tiempo pensando qué cocinar.

## Solución

SmartMeal centraliza un inventario ficticio de alimentos, recetas sugeridas, planes semanales y un formulario de contacto.

## Secciones del sitio

- Inicio
- Recetas
- Mis alimentos
- Planes alimenticios
- Contacto

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Google Fonts
- Visual Studio Code
- Git y GitHub

## Funcionalidades incluidas

- Navegación entre páginas.
- Diseño responsive para celular.
- Menú hamburguesa.
- Animaciones y efectos hover.
- Formulario de contacto con validaciones HTML5.
- Mensaje de confirmación al enviar el formulario.
- Inventario y recetas ficticias.
